# 🎓 StudentGuideAI

## AI-Powered Opportunity Navigator for Students

StudentGuideAI is a web application that helps students discover internships, hackathons, jobs and learning opportunities in one place.

It uses SerpApi-powered live web search and student-focused guidance to help students find relevant opportunities faster.

## 🚀 Features

- 🔎 Search for student opportunities
- 💼 Find internships
- 🏆 Discover hackathons
- 💻 Search for entry-level jobs
- 📚 Find courses and learning resources
- 🤖 Get student-focused career guidance
- 🌐 Get live web results using SerpApi

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- SerpApi
- python-dotenv
